# ALEX 추가 보완·실행 검증: 2026-10-12

기준 커밋은 **404b25d0ebead8c7a031d574abdc4b46a489618c**다. Linux에서 실행 가능한 공개본 검증을 확대하고, 실제로 재현된 문제를 수정했다. 사용자 PC의 설정·모델·대화 DB·GPU에는 접근하거나 변경하지 않았다.

## 결과와 수정

1. **로그인 만료·계정 중지 후 로컬 주인으로 바뀌던 문제:** 실제 쿠키 처리로 재현했다. 로컬 로그인 모드를 유지하고 유효하지 않은 로그인 쿠키를 주인 권한으로 바꾸지 않는다.
2. **동시 로그인 실패 횟수 누락:** 비밀번호 확인이 GIL을 놓을 때 실패 횟수를 잃었다. 모델 잠금과 독립된 로그인 잠금으로 보호한다. 임의 사용자 이름이 기존 계정 잠금을 지우던 문제도 수정해, 존재하지 않는 이름은 하나의 실패 버킷으로 제한한다.
3. **자료 업로드 응답·후속 요청 경쟁:** HTTP 응답을 보내는 동안 모델 잠금을 유지해, 클라이언트의 다음 요청이 불필요하게 409가 됐다. 저장·검증 후 잠금을 풀고 응답한다. 다른 스레드가 응답 시점에 잠금을 얻는지 회귀 검사한다.
4. **프로젝트 첫 대화 준비 중 중복 전송 가능:** 대화를 만드는 비동기 구간부터 입력을 잠근다. 실패·크기 거절 시 다시 입력할 수 있게 풀어 준다. 실제 브라우저에서 대화 생성 응답을 지연시켜 확인했다.
5. **Python 3.10의 검사 집계:** 모듈 경로 별칭과 실행 코드 경로가 다르면 실행된 unittest assertion을 0건으로 읽었다. 신뢰된 assertion의 code object로 식별하며, 모든 skip은 계속 0건이다.
6. **Linux pygame 시스템 글꼴:** 생성 코드의 글꼴 탐색이 subprocess 차단과 충돌했다. 격리 일꾼의 신뢰된 초기화에서 OS 도구 경로로 글꼴 캐시를 준비하고 읽기 전용 글꼴 경로를 허용한다. 생성 코드의 subprocess·네트워크·외부 쓰기 금지는 유지한다.
7. **공개본 배포 실패:** 공개하지 않는 개인 인계 파일을 필수로 요구하던 검사를 수정했다. 개인 설정·runtime·인계 파일·Node 의존성·브라우저 결과물을 배포·감사에서 제외한다.

pygame는 생성 코드 검사 일꾼에서만 선택적으로 사용한다. Core 기본 실행 의존성은 표준 라이브러리이며, 학습 패키지는 LoRA 일꾼에만 허용한다. 파일별 의존성 감사와 금지 import 회귀를 유지한다.
