# LTX 공개본 검증 — 2026-10-11

LTX 소리 포함 영상 연결과 실측에서 발견한 요청 분류·오디오 설명 잘림 수정을 기존 공개 ALEX에 반영했다. 공개본에 빠져 있던 ComfyUI 엔진을 복원하고, 실사용 core/app이 의존하는 최신 config/provider/runtime/web 및 모델 선택·미디어·RTL 연결 모듈과 회귀 검사를 함께 맞췄다.

## 검증

Windows Python 3.11에서 공개용 사본의 `python scripts/verify_release.py` 실행:

| 항목 | 결과 |
|---|---|
| 전체 단위·통합 검사, ResourceWarning 검사 포함 | 1,264개: 1,259 PASS, 5 SKIP, 실패 0; 72.547초 |
| Python 3.10 문법 호환 | PASS, 153개 파일 구문 분석; Python 3.10 실제 런타임 검증과는 별도 |
| 의존성 감사 | PASS |
| 라우터 골든 코퍼스 | 83/83 PASS |
| 보안 스모크 | 13/13 PASS |
| compileall·alpha·beta | PASS |
| 릴리스 종합 | PASS |
| 변경 파일 개인정보·실제 키 점검, diff 공백 점검 | PASS |

검사는 가짜 모델·도구 서버를 이용했다. GPU 모델을 새로 실행하거나 진행 중인 ALEX를 재시작하지 않았다.

## 원본과 공개본 구분

개발 PC 원본 전체 검사는 같은 1,264개 중 1,258 PASS, 5 SKIP, 별도로 작성된 게임의 Pygame 의존성 감사 1 FAIL이었다. 그 게임은 이번 ALEX 공개 변경 대상에 포함되지 않아 공개용 사본의 릴리스 감사는 통과했다. 원본 게임을 이동·삭제하거나 감사 예외를 추가하지 않았다.

개인 설정·대화 DB·모델 가중치·생성 영상·로그 원본·인수인계 원문은 게시하지 않는다. 설치 방법은 [LTX 영상 안내](LTX_VIDEO.md), 실제 GPU 실행 결과와 품질 한계는 [실측 기록](CODEX_LTX_LIVE_TEST_20261011.md)을 참고한다. 고양이/여기사 두 종류의 단회 실행은 장시간 안정성이나 모든 장면 지시의 성공률을 입증하지 않는다.
