- Windows PC 전체 검사(1,794개, 공개 사본에 없는 개인 파일 1건만 실패).

아직 결과가 저장소에 없는 것:
- `python -X utf8 scripts/measure_prompt_cache.py --live --pairs 4` — `stable_prompt_prefix` 판정(기준은 `docs/upstreams.json` `experiments[0].accept`).

이번에 새로 생긴 것:
- **새 폴더 만들기:** Windows 경로(`C:\…`)에서 만들고, '이 폴더로 작업' 으로 열리는지 본다.
- **Codex 의 폴더 선택 화면:** PC 사본에만 있고 저장소에는 아직 없다(11-08 확인).
  - 올릴 때는 이 창의 `#workspace-path` 칸을 채우거나 `/api/workspace/mkdir` 를 부르게 해서 새 폴더 기능과 겹치지 않게 한다.
  - 창 안의 이름 칸에 새 폴더 이름을 따로 받는다면 서버의 `folder_name_problem` 검사를 그대로 쓴다.
- **모델 노드·작업 노드:** 노트북 실기기 확인. ADR-125 의 한계 — 웹 검색·MCP·라이브러리 스킬은 그 기기 세션에 아직 넘기지 않는다.
