# 2026-10-22 공개 업데이트·인수인계

## 이번 버전

ALEX 자체 코딩 하네스와 이를 연결하는 최신 앱·웹·provider·검사를 함께 반영했다. OpenCode v1.18.34의 MIT 라이선스 코드·지시문에서 가져온 부분은 `jarvis/harness/OPENCODE_LICENSE.txt`와 파일별 출처를 보존한다. 외부 OpenCode 실행 파일을 쓰는 경로도 계속 선택할 수 있다. 모델 가중치를 학습하거나 변경한 작업은 아니다.

`/dev-auto`·`/build` 일꾼은 관련 테스트 지도, 400줄 분할 읽기, 기존 테스트 보호, 모델 밖의 독립 검사, 실패 출력으로 한 번 재수정, 미완료·검사 0건·전체 skip 거부를 지원한다. 하네스 사용 중 모델 설정을 저장하면 오류가 나던 문제도 수정했다. 별도 `/code` 화면은 세션·권한·질문·계획·변경·되돌리기를 지원한다.

연결 코드의 불일치를 피하기 위해 10월 12일 이후의 문서 첨부·HWP/HWPX·OCR·전체 문서 요약, 기억 검색, 뒤 작업, 월별 기록, 승인 기반 클라우드 위임, RTL/EDA 도구, 영상 자막·받아쓰기, `/live` CPU 받아쓰기·번역, 이미지 모델 선택도 현재 소스와 검사로 동기화했다. 추가 도구·모델은 포함하지 않으며 해당 기능은 별도 설치·설정이 필요하다.

## 하네스 선택

공개 코드의 기본 `coding_worker`는 호환성을 위해 `opencode`로 유지한다. 이 개발 PC만 로컬 설정에서 `harness`로 바꿨다. 다른 PC에서는 모델과 GPU 설정을 복사하지 말고 기존 로컬 설정의 다음 한 항목만 변경한다.

```json
{"coding_worker": "harness"}
```

또는 PowerShell에서 `$env:JARVIS_CODING_WORKER = "harness"`를 지정한 뒤 기존 시작 절차로 실행한다. `/code`는 관리자 계정 메뉴의 코딩 세션으로 연다. 처리 중인 작업이 없을 때 기존 lifecycle 절차로 재시작한다.

## 검사와 해석

- 개발 PC 전체 검사: 1,614개, 새 실패 0, 기존 개인 게임의 pygame 의존성 감사 실패 1, skip 5. 그 게임 파일은 공개 대상이 아니며 검사에서 성공을 만들기 위해 수정하지 않았다.
- 실제 종료 처리 수정 과제: 독립 7개 파일·130개 검사와 별도 목표 78개·종료 계약 2개를 통과했다. 일꾼 272.2초. 실제 `/code` 수정·검사·되돌리기와 데스크톱·모바일 화면도 확인했다.
- 보강 전 같은 1~5번 과제의 별도 지표는 기존 OpenCode 5/5, ALEX 하네스 4/5였다. ALEX 원본의 공식 엄격 지표는 기존 실패 때문에 0/5이며 여섯째 과제는 변이 위치가 없어 제외됐다. provider 문맥·출력 조건도 달랐다. 오늘의 한 과제 재통과를 전체 성공률·모델 학습·범용 우위로 확대하지 않는다.
- **2026-10-23 공개 사본 검증:** Python 3.11에서 1,615개 검사, 실패 0·skip 13(76.422초), 전체 릴리스 PASS(79.42초). 컴파일·3.10 문법·의존성·라우터 83/83·보안 13/13·알파·베타 검사를 통과했다. 3.10 실제 실행 재검증은 하지 않았다. 도구 환경 차이로 개발 PC보다 skip이 많다.
- 최초 공개 사본 검사에서는 새 문서·OCR·음성·영상 일꾼을 반영하지 못한 오래된 허용 목록 기대값이 실패했다. 파일별 정확한 패키지 목록으로 갱신하고, 코어·다른 일꾼의 torch import 차단 회귀 검사를 추가했다(관련 24개 통과). 실제 차단 규칙은 완화하지 않았다.
- 기존 설치의 wheel 도구가 없어 최초 패키지 생성은 실패했다. 추가 설치 없이 준비된 번들 런타임으로 다시 빌드했고, 하네스·code/live 화면·MIT 전문 포함과 wheel 직접 import·라이선스 읽기를 확인했다.

재현: `python scripts/verify_release.py`. 핵심 검사: `python -m unittest discover -s tests -p test_harness_verification.py`. 가짜 모델·격리 폴더 기반이며 실제 Ollama/Strata 추론을 시작하지 않는다. 선택 문서·OCR·EDA 환경이 없으면 일부 검사는 skip된다. 실제 모델의 단회 평가 증거는 개발 PC에 보존했다.

## 다음 순서

1. 모델 호출·스트림 대기 도중에도 시간 한도와 취소를 강제한다. 현재 시간 한도는 모델 차례 사이에서 검사하므로 호출 하나가 길어질 수 있다.
2. 여섯째 과제를 별도 버전으로 복구하고 소스·문맥·출력 상한을 고정해 기존 경로와 새 하네스를 여러 회차 비교한다. 과거 평가 원본은 보존한다.
3. `/code`에도 권한 단계에 맞는 독립 검사·재수정 연결을 검토한다. 현재 독립 검사는 HarnessWorker 경로에만 있다.
4. 관련 검사 선정은 직접 import·변경 함수 사용에 기반한 휴리스틱이므로 전체 회귀 검사를 계속 유지한다.

## 공개하지 않는 것

`jarvis.local.json`, DB·대화·자료·생성물·로그·평가 원문·모델·도구 환경·브라우저 프로필·두 NEXT 원문·개인 게임은 제외한다. 상세 로컬 인수인계는 기존 GPT_NEXT.md와 CLAUDE_NEXT.md 맨 위에 남겼다. 이 공개 문서는 후속 개발에 필요한 코드·검사·한계만 담는다. `laptop` 브랜치는 수정하거나 병합하지 않는다.
