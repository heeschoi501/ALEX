# 2026-10-23 공개 업데이트·인수인계

## 이번 버전

1. **코딩 하네스 속도·검사 보강** — 독립 관련 검사가 상수 하나만 바뀌어도 모듈 전체를 다시 돌리던 것을, 바뀐 이름과 그것을 읽는 함수만 고르게 했다. 에이전트가 마지막 수정 뒤 직접 돌려 통과한 시험 파일은 실행 기록(종료 코드·실행 수)을 근거로 다시 돌리지 않는다. 남은 것은 ALEX 전체 검사처럼 파일별로 나란히 돈다. 하네스 셸 실행은 ALEX 시험과 같은 UTF-8 모드다.
2. **코딩 경험으로 배우기** — 코딩 세션이 독립 검사까지 하면 결과를 `dev-outcomes` 기록으로 남기고 `/dev-learn` 이 자동 수정 기록과 함께 절차 교훈을 뽑는다. 설정 `coding_auto_learn_enabled` 를 켜면 쉬는 중(기다리는 요청 없음)에 안 배운 기록이 3건 이상일 때 뒤 작업 차례로 자동 실행한다. 사람이 고른 교훈은 `/dev-insights skill 번호 [이름]` 으로 하네스 스킬(`.alex/skills/이름/SKILL.md`)이 된다. 교훈은 `coding_insights_enabled` 일 때 하네스·코딩 세션 지시문에도 붙는다.
3. **OpenCode 무료 모델** — OpenCode 와 같은 목록(models.dev 의 opencode 공급자)에서 입력 비용 0·지원 종료/실험 아님·도구 호출 가능한 모델만 보인다. OpenCode 의 무료 단계는 OpenCode 안에서만 쓸 수 있으므로(밖에서 직접 부르면 403 FreeTierError) ALEX 는 `opencode.exe` 를 통해 쓴다. `/dev-auto`·`/build` 일꾼(설정 `coding_free_model`)과 코딩 세션(만들 때 모델 선택)에서 고를 수 있다. 코드가 opencode.ai 로 전송되므로 고를 때만 쓰며, 보내는 복사본에서 기록·데이터·실행 환경·개인 설정(.env·로컬 설정)은 뺀다. 무료 세션의 변경은 ALEX 권한 단계대로(확인 후 실행이면 diff 를 보여 묻고) 들이고 되돌리기·독립 검사를 거친다.
4. **설정·화면** — 설정의 '코딩 에이전트 · API' 칸(일꾼·코딩 모델·교훈·자동 학습·코딩 세션 열기·API 토큰 복사, 바로 적용), 입력창의 '코딩 세션' 버튼.
5. **다시 켜기** — 실행기를 다시 실행하면 켜진 웹이 옛 코드일 때 쉬는 중이면 웹만 끄고 새로 켠다(모델 서버는 그대로, 일하는 중이면 끄지 않고 알림). 계정 메뉴 '다시 켜기' 는 웹이 실행기를 따로 띄우고 스스로 꺼진 뒤 새로 켜지고 화면이 저절로 새로고침된다. 코딩 세션이 일하는 중이면 종료·다시 켜기를 거절한다.

## 검사와 해석

- 같은 조건 비교(고정 소스·같은 모델·일꾼 180초): ALEX 하네스 1/6 → 2/6, 기존 OpenCode 경로 2/6. 제한 없는 자동 수정 유효 5과제 재평가는 5/5(새 실패 0, 이전 4/5). 개발 PC 의 단회 측정이며 범용 우위로 확대하지 않는다.
- 무료 모델 경로는 가짜 OpenCode 로 시험하고, 개발 PC 에서 연습용 폴더 한 과제를 실제로 확인했다(성능 평가는 아님). 무료 모델의 사용 조건·한도는 OpenCode 쪽에 따른다.
- 재현: `python scripts/verify_release.py`. 핵심: `test_harness_verification.py`·`test_free_sessions.py`·`test_freemodels.py`·`test_launcher_stale.py`·`test_web.py`. 가짜 모델·가짜 서버 기반이며 실제 추론·네트워크를 쓰지 않는다.

## 공개하지 않는 것

로컬 설정·DB·대화·로그·평가 원문·모델·도구 환경·두 NEXT 원문·개인 게임은 제외한다.

## 오후 갱신(같은 날)

1. **딥서치(Codex, ADR-116)** — 복합 비교·근거 조사 질문은 명령 없이 자동으로 여러 검색·본문을 읽고 출처와 한계를 붙여 보고한다. `/research 주제`(`/deepsearch`)로 직접 요청도 된다. 간단한 최신 사실은 기존 빠른 검색. 상세 [CODEX_DEEPSEARCH_20261023.md](CODEX_DEEPSEARCH_20261023.md).
2. **말로 파일 고치기** — 채팅에 '프로젝트에 있는 파일 이름 + 고쳐줘' 또는 '코딩 세션에서 ~해줘' 라고 하면 코딩 세션이 그 파일을 고친다. 허락은 채팅에서 '응'(이번만)·'항상'·'아니', '되돌려줘' 로 되돌린다. 파일을 집지 않은 '코드 짜줘' 는 예전처럼 코드를 답으로 준다(`jarvis/harness/intent.py`).
3. **자기 기능 알기** — 기능을 묻는 질문에 실제 명령 목록(/help)·화면 설명·권한 안내에서 맞는 줄을 골라 붙여 정확히 답한다(`jarvis/selfknow.py`). 새 기능이 생기면 저절로 들어간다.
4. **스스로 점검(준비만)** — `/self-check [개수]`: 자기 기능 질문을 스스로 풀고 틀린 것을 교훈으로. 정답은 코드에서 나온다. 관리자·부를 때만·그래픽카드 80℃ 이상이면 멈춤. 자동 실행 없음(`jarvis/selfcheck.py`).
5. **입력창 '오픈코드 API'** — OpenCode 무료 모델을 입력창에서 고른다(설정의 코딩 모델과 같은 값).
6. **문서 고치기 엔진(미연결)** — 워드·엑셀·PPT 를 서식 그대로 두고 글자만 고치는 엔진(`jarvis/officeedit.py`, 시험 포함). 채팅 연결(올린 문서→고친 사본, PC 문서→허락 뒤 그 자리)은 다음 작업이다.

검사: 공개 사본 `python scripts/verify_release.py`. 핵심: `test_code_chat.py`·`test_selfknow.py`·`test_officeedit.py`·`test_research.py`. 가짜 모델·가짜 서버 기반.
