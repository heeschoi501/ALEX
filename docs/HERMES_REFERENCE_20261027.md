# Hermes Agent 참고 — 비교와 들여온 것 (2026-10-27, Claude 클라우드)

[Hermes Agent](https://github.com/NousResearch/hermes-agent)(Nous Research, MIT)는 '스스로 배우는' 개인 에이전트다. 소스(커밋 `085f562a`)를 직접 읽고 ALEX 와 겹치는 곳만 비교했다. 그대로 옮긴 코드는 `jarvis/threats.py` 의 패턴 목록뿐이고 라이선스 전문은 `jarvis/HERMES_LICENSE.txt` 에 있다. 나머지는 방식만 참고해 ALEX 코드로 새로 썼다.

## 비교

| 항목 | Hermes Agent | ALEX(이번 작업 전) | 이번에 한 것 |
|---|---|---|---|
| 시스템 프롬프트 | 세션 시작 때 메모리를 굳혀(frozen snapshot) 중간에 바꾸지 않는다 — 모델 서버의 프롬프트 캐시를 살리려고 | 맨 앞 지시 안에 분 단위 시각, 그 뒤에 질문마다 다시 고르는 메모·교훈·자료 → 매 차례 대화 전체를 다시 읽는다 | 설정 `stable_prompt_prefix`(기본 꺼짐, ADR-119). 모델 없이 잰 같은 앞부분 비율 6.5% → 79%(셋째 차례부터 약 92%) |
| 배울 것 고르기 | 환경 탓 실패·'도구가 안 된다'·못 푼 시도·일시 오류는 배우지 않는다고 명시 | `/dev-learn` 지시문에 없음 | 지시문 + 코드 거름(ADR-120) |
| 프롬프트에 들어가는 남의 글 | 메모리·스킬·문맥 파일·도구 결과에 주입 패턴 검사(막기/경고) | '지시로 취급하지 말라' 안내만. 웹에서 찾은 교훈은 사람 승인 없이 씀 | 웹·저장 자료는 경고, 교훈은 뺌(ADR-120) |
| 스킬 정리 | 안 쓰면 오래됨→보관, 지우지 않음 | 점수 0 교훈은 지워짐 | 보관함·되살리기(ADR-120) |
| 지난 대화 찾기 | SQLite FTS5 + 모델 요약 | 제목만 걸러 봄 | 본문 검색(`/chat-search`, 옆 목록 검색) |
| 모델이 스스로 쓰는 메모리 | 2,200/1,375자 한도, 쓰기 승인 단계 있음 | 사람이 `/remember` | 들이지 않음 — ALEX 는 사람 승인 원칙 |
| 메신저·원격 실행 환경·학습 데이터 생성 | 있음 | 없음 | 들이지 않음 — ALEX 방향과 다름 |

## PC 에서 할 것

1. `python -X utf8 scripts/measure_prompt_cache.py --live` — 순서를 끔→켬→끔으로 같은 질문에 돌려 첫 글자 시간·입력 토큰·답을 `logs/prompt-cache-*.json` 에 남긴다(임시 DB). 빨라지고 답이 나빠지지 않으면 `jarvis.local.json` 에 `"stable_prompt_prefix": true`.
2. Strata 서버가 앞부분이 같은 요청을 다시 읽지 않는지(프롬프트 캐시)도 이 측정으로 드러난다 — 차이가 없으면 서버 쪽 설정을 확인한다.

## 한계

- 순서를 바꾸면 교훈·자료가 질문에 더 가까워진다. 답의 질이 달라질 수 있어 기본은 꺼 두었다.
- 주입 패턴은 어림이다. 검사에 안 걸린 지시도 있을 수 있어 '지시로 따르지 말라' 안내는 그대로 둔다. 이 저장소의 문서 85개에서는 하나도 걸리지 않았다.
- 대화 본문 검색은 색인 없이 훑는다. 대화가 수십만 개로 늘면 느려질 수 있다(지금은 최근 일치 2,000개까지만 본다).
