## 4. 전력 소비량

**실측(nvidia-smi 5초 간격, CPU 사용률 10초 간격, 19:12~19:57):**

| 단계 | GPU 전력 평균 / 최대 | GPU 사용률 | CPU 사용률 |
|---|---|---|---|
| 생성(48K, 1,200토큰) | 76W / 80W | 35% | 60% |
| 읽기(2.7만 토큰) | 239W / 246W | 88% | 57% |

| 쉼(모델 내림) | 13W | 0% | 3% |

- **생성할 때 그래픽카드가 76W, 35%만 쓴다.** CPU가 처리하는 층을 기다리기 때문이다. 메모리가 병목이라는 직접 증거다.

**추정(CPU 전력과 벽 전력은 재지 않음):**
- CPU(9800X3D)는 사용률 60%에서 약 90~120W로 본다.
- 평가 중 PC 전체는 약 250~300W, 읽기 순간에는 약 450W, 쉴 때는 약 80~100W로 본다(브론즈 전원 효율 약 85% 반영).
- 에너지는 평가 11개 한 번(3~3.6시간)에 약 0.8~1.1kWh, 과제 1개에 약 0.07~0.1kWh다. 가정용 kWh당 약 120~300원으로 치면 평가 한 번에 약 100~300원이다.
- 평가는 GPU를 세게 쓰지 않는다. 4일간 4번 있었던 갑작스런 꺼짐(Kernel-Power 41)은 125B(CPU 최대)나 영상 생성(GPU 최대)처럼 더 센 부하에서 났을 가능성이 크다. 전원은 보급형 850W 브론즈다. GPU 전력 한도 300W와 CPU ECO 모드를 권한다.
