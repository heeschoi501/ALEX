# 로컬 문서 지식

PDF·UTF-8 TXT/MD/RST/CSV/Verilog/Python 자료를 저장하고 새 대화·앱 재시작 후에도 관련 질문에 원문을 참고한다.
저장은 모델 가중치 학습이나 검증된 설계 규칙 승인과 다르다. 파일에서 뽑은 본문만 검색용 자료가 된다.

## 사용

웹 오른쪽 **학습 자료**에서 이 PC의 파일 경로를 입력하거나 **자료 파일 올리기**를 누른다.
파일 선택/명령 제출이 실제 저장 요청이다. 화면을 열거나 파일 경로를 예제로 보여주는 것만으로 저장하지 않는다.

```text
/learn-file "C:\자료\강의.pdf"
/knowledge
/knowledge-search Verilog LRM
/ask-knowledge 자료ID :: 이 강의에서 권하는 학습 방법은?
/forget-knowledge 자료ID --yes
```

절대 경로는 프로젝트 밖이어도 사용자가 명시적으로 지정한 파일 하나만 읽는다.
상대 경로는 현재 프로젝트 기준이다. 네트워크 경로·인증정보 폴더·암호 파일은 받지 않는다.
`C:\자료\강의.pdf를 학습해줘`처럼 경로와 저장 요청만 있는 문장도 처리한다.
다른 문장의 예시 경로나 자료 내부 지시를 보고 새 파일을 읽지는 않는다.

## 저장·검색

- `data/knowledge/knowledge.db`: 파일 해시·제목·출처 경로·페이지·본문 조각과 FTS5 검색 색인.
- `data/knowledge/sources/`: SHA256 이름의 원본 사본. 원본 파일을 지우거나 바꿔도 저장한 자료는 남는다.
- 동일 내용 재등록은 중복 방지. 내용이 바뀐 파일은 별도 버전으로 남는다.
- 검색은 영어 단어·한국어 두 글자 조각 기반의 FTS5 검색이다. 임베딩/의미 검색은 아니다.
- 일반 로컬 대화에서는 관련된 본문만 입력 예산 안에 추가한다. 앱이 실제 전달한 원문 출처·쪽수를 답 끝에 표시한다.
- 특정 자료 질문은 `/ask-knowledge ID :: 질문`. 본문 일부만 들어갈 수 있어 대형 문서 전체를 읽었다고 해석하면 안 된다.
- 자료가 포함된 요청에는 자동 웹 검색과 Cloud fallback을 사용하지 않는다. Cloud 문맥 필터는 자료를 항상 제거한다.
  이전 답변을 복사해 사용자가 직접 Cloud에 보내는 행위까지 통제하는 기능은 아니다.
- 삭제 명령은 색인·저장 사본을 지운다. 원본, 이전 대화 답변, 사용자가 따로 만든 백업은 지우지 않는다.

## PDF 읽기 환경

Core의 Python 표준 라이브러리 정책을 유지하고 pypdf를 별도 환경의 일꾼으로 실행한다.
앱이 자동 다운로드/설치하지 않는다. Windows 기본 배치:

```powershell
py -3.11 -m venv C:\ALEX\tools\documents\venv
C:\ALEX\tools\documents\venv\Scripts\python.exe -m pip install pypdf==6.20.0
```

다른 위치는 `JARVIS_PDF_PYTHON` 환경변수로 해당 환경의 Python 전체 경로를 지정한다.
기본 경로는 프로젝트 상위 폴더의 `tools/documents/venv`다. Linux에서는 `bin/python`을 찾는다.

자료 20MB·PDF 400쪽·본문 60만 자·한 페이지 내용 스트림 5MB·추출 40초 제한.
암호화 PDF·잘못된 PDF·전체 본문이 없는 스캔 PDF는 실패를 알린다. 일부 빈 페이지는 경고한다.
PDF의 그림·회로도·수식 배치·스캔 이미지를 해석하는 OCR/Vision 기능은 포함하지 않는다.
원문과 페이지 번호를 보존하되 PDF 텍스트 읽기 순서·표 구조가 원본 화면과 같다고 보장하지 않는다.

## 검증 기준

지속성, 동일 자료 중복, 페이지 출처, 문맥 예산, 자료 삭제, 로컬 모델만 호출,
Cloud 필터, 지시문을 데이터로 취급, 인증·세션·파일 크기·지원 형식, PDF 오류를 검사한다.
자료 저장만으로 Verilog 설계 실력이 향상됐다고 평가하지 않는다.
