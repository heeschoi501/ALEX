# 노트북 Strata 최적화 정리 — Qwen3.6-35B-A3B (2026-10-16)

노트북: RTX 4070 Laptop 8GB · RAM 31.2GB · Ryzen 9 7945HX(16코어, AVX-512) · PCIe 4.0 x8(실측 13.4GB/s).
Strata 0.1.44.1(CUDA 12 엔진, 드라이버 572.70). 근거는 Strata 소스(`src/qwen35/q36_engine.cu`, `docs/HOW_IT_WORKS.md`)와
이 노트북의 엔진 로그(`tools/strata/strata-coder-iq1_m.log`, `strata-qwen36-ud-q4_k_xl.log`). **속도는 재지 않았다.**

## 1. 결론

- Strata 의 빠른 비결(디스크에 미리 재배열한 전문가 묶음, 자주 쓰는 전문가 목록, 저RAM 모드 등)은 **Flash-Next 계열 전용**이다.
  Qwen3.6 은 별도의 단순한 경로(새 모델 계획 T1)로 돈다.
- 노트북의 Qwen3.6 이 느렸던 직접 원인은 **그래픽카드에 전문가가 0개**였던 것이다(VRAM 이 버퍼로 다 찼다).
  문맥 16K·입력 조각 512 로 바꿔 **4개/층**이 됐고, 켜는 시간이 275초 → 약 80초로 줄었다.
- 설정만으로 더 갈 수 있는 곳은 **약 19개/층(전체 전문가의 7%)** 까지다. 그 이상은 엔진 코드를 고쳐야 한다.

## 2. 기존 Strata(Flash-Next) 방식 — 노트북 Coder 로그로 본 것

| 장치 | 하는 일 | 노트북 Coder 로그 |
|---|---|---|
| 전문가 묶음(pack) | 설치 때 전문가를 엔진이 바로 읽는 모양으로 디스크에 다시 써 둔다 | 1,406MiB 가중치를 1.2초에 적재 |
| 전문가 순위 목록(profile) | 미리 잰 "자주 불리는 전문가" 순위로 켜자마자 VRAM 캐시를 채운다 | `expert-profile-coder.bin` 으로 309칸을 0.3초에 채움 |
| VRAM 전문가 캐시 | 남은 VRAM 을 자주 쓰는 전문가로 채움. 여유분이 너무 크면 스스로 줄인다 | 여유 700→615MiB 로 낮춰 309칸 확보 |
| 저RAM 모드 | 전문가 전체를 RAM 에 두지 않고 파일에서 매핑, 가장 뜨거운 것만 RAM 에 고정 | 22.8GiB 중 6.02GiB 만 고정, 나머지는 파일에서 |
| 메모리 보호 | 윈도우 커밋 한도·여유 RAM 을 보고 계획을 줄이거나 경고 | 커밋 4.5GiB 남음 경고 |
| CPU 작업자 배치 | 물리 코어마다 작업자 1개, GPU 인터럽트가 몰리는 코어 0 은 호스트 스레드 | 15명 + 호스트 |
| MTP 초안 + 검증 창 | 작은 초안층이 다음 단어 몇 개를 추측, 본 모델이 한 번에 확인 | 초안층 839MiB, 창 6토큰 |
| 낮은 순위 전문가 건너뛰기 | 캐시에 없는 7순위 이하 전문가는 건너뜀(12~16GB 카드 +10~20%) | 켜짐(기본) |
| 입력 조각 자동 | VRAM 에 맞춰 입력 조각을 줄이고 캐시 칸을 빌려 씀 | 256토큰, 146칸 빌림 |
| n-gram 표(SSD) | 28.8GB 표를 토큰마다 몇 줄만 읽음 | Flash-Next 구조에만 있음 |

## 3. Qwen3.6 경로 — 있는 것과 없는 것

| 장치 | Qwen3.6 | 비고 |
|---|---|---|
| 전문가 묶음 | **없음** — 켤 때마다 GGUF 에서 다시 묶는다 | 66~91초가 여기서 든다 |
| 순위 목록 | **없음** — 처음엔 0번부터 차례로 칸을 채운다 | |
| 실행 중 교체 | **있음** — 라우팅 횟수를 세어 32토큰마다 최대 8개, 긴 입력 직후 최대 2,048개 교체 | 첫 대화 뒤부터 맞춰진다 |
| VRAM 캐시 | 있음 — 층마다 같은 칸 수. 여유 768MiB 고정(스스로 줄이지 않음) | `--expert-vram` 으로 직접 지정 가능 |
| RAM | 전문가 18.75GiB 전부 RAM 에 복사, 고정(pinned) 실패 시 일반 메모리 | 노트북은 둘 다 일반 메모리 → RAM 이 모자라면 디스크로 밀림 |
| 저RAM 모드·메모리 보호 | **없음** | |
| CPU 작업자 | 있음 — 물리 코어마다 1개(16) | |
| MTP | 있음 — GGUF 에 든 MTP 블록, `--mtp 2` | |
| 긴 입력 | 128행보다 큰 조각은 층마다 전문가를 그래픽카드로 흘려보냄 — **작업 공간 1.10GiB 고정** | 조각 크기와 무관(한 층 전문가 × 2) |
| 낮은 순위 건너뛰기·n-gram 표 | 없음 | |

## 4. 노트북에서 실제로 벌어진 일

| | 32K · 조각 2048(설치값) | 16K · 조각 512(현재) |
|---|---|---|
| 엔진 버퍼 뒤 남은 VRAM | 0.67GiB | 2.16GiB |
| 그래픽카드의 전문가 | **0 / 256** (요청 19,704건 중 GPU 0%) | **4 / 256** (0.29GiB) |
| 전문가 배치 + 준비 | 91초 + 147~172초 | 66초 + 12초 |
| 시작 전 여유 RAM | 11.5GB(다른 프로그램 ~20GB) | 20.8GB |

칸 수 계산: (남은 VRAM − 여유 768MiB − 작업 공간 1.10GiB) ÷ 칸당 약 74MB(40층 + MTP 블록에서 전문가 하나씩).

## 5. 설정 항목과 권장값

| 항목 | 현재 | 권장 | 효과 | 대가·위험 |
|---|---|---|---|---|
| `--max-context` | 16384 ✅ | 16384 | 캐시 0.7GB 확보 | 8K 로 더 줄이면 ALEX 출력 한도를 4096 이하로 낮춰야 함 |
| `--prefill`(입력 조각) | 512 ✅ | 512 | 활성값 버퍼 축소 | 긴 입력 읽기가 약간 느려질 수 있음 |
| 다른 프로그램 닫기 | — | **켜기 전에** | 전문가가 디스크로 밀리지 않음. 여유가 충분하면 고정 메모리도 될 수 있음 | 사용자 몫 |
| `STRATA_Q36_NO_MMQ=1` | 꺼짐 | **다음 후보** | 작업 공간 1.10GiB 반환 → 약 19개/층 | 긴 입력을 그래픽카드로 흘려보내지 않고 CPU 가 더 맡는다 → 긴 입력 읽기가 느려질 수 있음 |
| `--expert-vram` | 자동(남은 VRAM − 768MiB) | 자동 유지 | 여유분만큼 몇 칸 더 | VRAM 이 1GB 밑이면 드라이버가 GPU 메모리를 RAM 으로 빼 답이 몇 tok/s 로 떨어질 수 있음(Strata #2065) |
| `--mtp` | 2 | 2 유지 | 추측 가속 | 끄면 VRAM 조금 확보, 가속은 잃음 |
| `--cpu-threads` | 16(자동) | 유지 | 물리 코어마다 1개 | |

`STRATA_Q36_NO_MMQ` 는 Strata 설정 파일의 `"env"` 블록에 넣는다(Strata 설치 안내가 같은 방식으로 `STRATA_RESIDENT_HEADROOM_GIB` 를 권한다).
효과는 재 보기 전까지 추정이다.

## 6. 엔진 코드를 고쳐야만 되는 것

Flash-Next 의 장치를 Qwen3.6 경로로 옮기는 일이다. 엔진을 다시 빌드해야 한다(Visual Studio Build Tools + CUDA Toolkit, Strata setup 의 `--build`).
Strata 쪽에 이슈·PR 로 제안하는 편이 맞다.

| 개선 | 기대 효과 | 크기 |
|---|---|---|
| 순위 목록 저장·적재 | 켜자마자 뜨거운 전문가로 칸을 채움(지금은 첫 대화가 끝나야 맞춰짐) | 작음 — 실행 중 세는 점수가 이미 있다 |
| 디스크 묶음 | 켤 때마다 드는 66~91초 제거 | 중간 |
| 저RAM 모드 | 18.75GiB 전체 대신 뜨거운 것만 RAM 에 고정 — 31GB 노트북에 가장 큼 | 큼 |
| 낮은 순위 전문가 건너뛰기 | Flash-Next 기준 +10~20% | 중간, 답이 조금 달라짐 |
| 작업 공간을 조각 크기에 맞추기 | 1.10GiB 중 일부 반환 | 작음 |

## 7. ALEX 쪽 설정(노트북 `jarvis.local.json`)

- 적용됨: `local_backend: strata`, `strata_config: strata-qwen36-ud-q4_k_xl.json`, `strata_num_ctx: 16384`(입력 예산 5,529자),
  `strata_max_output_tokens: 6144`.
- 결정 대기: ① 생각 정도(`strata_reasoning_effort` medium → low 면 첫 답이 빨라짐) ② 샘플링 — ALEX 가 Strata 에 temperature 등을
  보내지 않아 greedy 로 돈다. Qwen 권장값(생각: 1.0/0.95/20, 생각 끔: 0.7/0.8/20 + presence 1.5)을 넣는 수정은 데스크톱 답에도
  영향을 주므로 사용자 결정 뒤에.
